# WARP.md

This file provides guidance to WARP (warp.dev) when working with code in this repository.

## Project Overview

This is an Expo React Native application built with:
- **Expo SDK ~54.0** with React Native 0.81.5 and React 19.1.0
- **TypeScript** with strict mode enabled
- **Expo Router v6** for file-based navigation
- **React Native Reanimated** and **Gesture Handler** for animations
- **Cross-platform support**: iOS, Android, and Web

### Key Features Enabled
- Expo's new architecture (`newArchEnabled: true`)
- Typed routes (`typedRoutes: true`)
- React Compiler experimental feature (`reactCompiler: true`)

## Development Commands

### Starting the App
```bash
npm start          # Start Expo dev server with menu
npm run android    # Start on Android emulator
npm run ios        # Start on iOS simulator
npm run web        # Start web version
```

### Code Quality
```bash
npm run lint       # Run ESLint with Expo config
```

### Project Reset
```bash
npm run reset-project  # Moves starter code to app-example/, creates blank app/
```

## Architecture

### File-Based Routing
The app uses Expo Router's file-based routing system:
- `app/_layout.tsx` - Root layout with theme provider and stack navigation
- `app/(tabs)/_layout.tsx` - Tab bar layout with Home and Explore screens
- `app/(tabs)/index.tsx` - Home screen
- `app/(tabs)/explore.tsx` - Explore screen
- `app/modal.tsx` - Modal presentation screen

The root layout sets `anchor: '(tabs)'` to make the tabs layout the initial screen.

### Path Aliases
TypeScript is configured with `@/*` alias pointing to the project root, e.g.:
```typescript
import { useColorScheme } from '@/hooks/use-color-scheme';
import { Colors } from '@/constants/theme';
```

### Theming System
The app supports light/dark mode theming:
- **Theme constants**: `constants/theme.ts` exports `Colors` and `Fonts`
- **Platform-specific hooks**: `hooks/use-color-scheme.ts` (native) and `hooks/use-color-scheme.web.ts` (web)
- **Theme hook**: `hooks/use-theme-color.ts` for accessing theme colors
- **Themed components**: `ThemedText` and `ThemedView` in `components/` automatically adapt to color scheme

Color scheme detection uses platform-specific implementations with fallback behavior.

### Component Organization
- **Root components/**: Reusable UI components (external-link, haptic-tab, parallax-scroll-view, etc.)
- **components/ui/**: UI primitives (collapsible, icon-symbol)
- Themed components accept `lightColor` and `darkColor` props to override theme defaults

### Platform Considerations
- **Icon system**: `icon-symbol.tsx` with iOS-specific variant (`icon-symbol.ios.tsx`) using SF Symbols
- **Font system**: Platform-specific font stacks defined in `constants/theme.ts` (iOS uses SF fonts, web uses system fonts)
- Native folders (`/ios`, `/android`) are gitignored and generated by Expo

## Important Notes

- This project uses **npm** as its package manager (not bun, despite user's preference rule)
- Native iOS/Android folders are generated - don't manually edit them
- Web output is configured as static in `app.json`
- ESLint uses Expo's flat config format
- Expo Router requires specific directory structure - don't rename `app/` folder
